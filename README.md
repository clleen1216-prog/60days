# 兩個月英文口說聽力速成 App 課程與原型開發

> 精選旅遊與生存場景，60天系統性突破英文聽說障礙

建立英文學習APP Crash Course 目標兩個月顯著提升 英文口說聽力。場景日常對話 旅遊 申請美國簽證 飛機 海關 叫車 交通 飯店 餐廳 觀光 small talk 自我介紹 打招呼問好

## 本機開發啟動
```bash
npm install
npm run dev
```

## 建置與部署至 Vercel
```bash
npm run build
```
已內附 `vercel.json`（Vite Framework，Output Directory 為 `dist`），可直接推送至 GitHub 後匯入 Vercel 或直接透過 Vercel API 部署上線。
